## Datenschutzerklärung (Privacy Policy)

Der Schutz von personenbezogenen Daten ist uns ein wichtiges Anliegen. Diese Datenschutzerklärung erläutert, welche Daten durch die Nutzung des Discord-Bots verarbeitet werden und welche Rechte den Nutzern zustehen.

### 1. Datenverarbeitung bei Interaktion
Um Funktionen auf Discord bereitzustellen, verarbeitet der Bot technische Daten, die über die Programmierschnittstelle (API) von Discord übermittelt werden. Dazu gehören:
* **Discord-Identifikationsnummer (User-ID):** Eine eindeutige, unveränderliche Zahlenfolge zur Identifikation des Nutzers innerhalb des Systems.
* **Nutzername und Server-Spitzname:** Zur korrekten Ansprache und Darstellung in Protokollen oder Ranglisten.
* **Server- und Kanal-IDs:** Zur Zuordnung, auf welchem Server und in welchem Kanal ein Befehl ausgeführt wurde.
* **Nachrichteninhalte:** Der Bot analysiert Textnachrichten ausschließlich dann, wenn sie als Befehl an den Bot gerichtet sind (z. B. durch ein festgelegtes Präfix oder eine Erwähnung). Eine kontinuierliche Überwachung oder Speicherung von privaten Chatverläufen findet nicht statt.

### 2. Speicherung und Weitergabe von Daten
* **Temporäre Verarbeitung:** Daten, die für die einmalige Ausführung eines Befehls notwendig sind, werden flüchtig im Arbeitsspeicher verarbeitet und nach der Antwort sofort verworfen.
* **Dauerhafte Speicherung:** Daten für dauerhafte Funktionen (wie Level-Systeme, serverbezogene Einstellungen oder Wirtschaftssysteme) werden in einer sicheren Datenbank hinterlegt.
* **Weitergabe an Dritte:** Es findet keinerlei Weitergabe, kein Verkauf und keine Bereitstellung der verarbeiteten Daten an Dritte zu kommerziellen oder Werbezwecken statt.

### 3. Rechte der Nutzer (Auskunft und Löschung)
Nutzer haben jederzeit das Recht:
* Auskunft über die vom Bot über sie gespeicherten Daten zu erhalten.
* Die vollständige Löschung aller mit ihrer Discord-ID verknüpften Daten aus der Datenbank des Bots zu verlangen.
Für die Durchsetzung dieser Rechte genügt eine formlose Kontaktaufnahme mit der Administration des Bots.

### 4. Änderungen der Datenschutzerklärung
Die Betreiber behalten sich vor, diese Datenschutzerklärung anzupassen, wenn neue Funktionen des Bots dies erforderlich machen. Die fortgesetzte Nutzung des Bots nach einer Änderung gilt als Zustimmung.
